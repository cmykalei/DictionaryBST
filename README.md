# Dictionary BST
Binary Search Tree dictionary data structure implementation in Java.

## Project 🌳
```
.
├── DictionaryBST.java
├── DictionaryLookup.java
├── DictionaryNode.java
├── LookupCommandLine.java
└── TreeFormatter.java
```

### Usage
Compile and run the command-line lookup tool:
```bash
javac LookupCommandLine.java
java LookupCommandLine
```

## Commands
1. To run the dictionary lookup use `java LookupCommandLine`.
